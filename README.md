# Python Koans
Code challenges for Python.

## For Contributors
Contributors can run this command to get their environment setup.
```shell
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

These are the top level packages in `requirements.txt`.
- `astor`
- `nbformat`


Run this after modifying package installations.
```shell
pip freeze > requirements.txt
```
