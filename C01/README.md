# C01 Exercise: Data Types, Variables, and Basic Operations
Welcome to your first exercise!

This exercise is designed to help you practice Python basics: data types, variables, arithmetic, string operations, and type conversion.

- Data Types
  - `bool`: A *boolean* is a two state value that represents `True` or `False`.
  - `int`: These are whole *integer* numbers.
  - `float`: These are fractional *floating-point* numbers.
  - `str`: These are *strings* of characters, better known as text.
- Basic Operations
  - Arithmetic operations (`+`, `-`, `*`, `/`)
  - String operations (concatenate: `+`, repeat: `*`)
- Type Conversions
  - `int()`: Converts a value into an integer.
  - `float()`: Converts a value into a float.
  - `str()`: Converts a value into a string.
