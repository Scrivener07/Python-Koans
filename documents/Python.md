### DocString Format
This is a potential standardization of challenge docstrings.
```python
"""
<Short description>

Instructions:
    <Clear, step-by-step instructions for the challenge.>

Sample Data:
    Input: <example input>
    Output: <expected output>

Result Format:
    <Describe if the result should be returned or printed.>

Concepts:
    <Link to relevant documentation of Python concepts>

Notes:
    <Any hints or edge cases.>

Returns:
    <Type and description of the result>
"""
```
